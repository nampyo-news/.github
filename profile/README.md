## 🔎 남표뉴스 한 줄 소개

> **“같은 이슈, 다른 프레임.
> 진보·보수 언론의 키워드 차이를 데이터로 보여주는 인터랙티브 뉴스 대시보드.”**

남표뉴스는 한국 주요 일간지 기사들을 모아

* 언론사를 **진보(blue) / 보수(red)** 로 나누고
* 기사에서 추출된 **키워드(명사)** 를 진영별로 집계한 뒤
* **상위 키워드 TOP 10과 비율**을 시각화하여
  각 진영이 어떤 단어로 이슈를 이야기하는지 보여주는 프로젝트입니다.

## 📝 Abstract (논문 초록)

> 이 섹션에는 **남표뉴스 웹 프로젝트를 기반으로 작성한 논문 초록**을 넣습니다.
> 아래 예시는 형식 참고용이며, 실제 README에서는 **전부 삭제하고 본인 초록**으로 교체해 주세요.

**Abstract (예시)**
Nampyo News is a web-based system that analyzes framing differences between progressive and conservative newspapers in South Korea. Using news data related to the Yellow Envelope Act (노란봉투법), the system collects articles from four major dailies, classifies them into political camps, and visualizes keyword distributions for each side. Based on 744 articles published over 119 days, the system extracts noun-based keywords from BIGKINDS data and aggregates their frequencies by political camp. The results show that progressive media emphasize labor-related concepts such as “노동자”, “원청”, and “교섭”, whereas conservative media focus more on political and economic actors such as “민주당”, “대표”, and “기업”. By providing these patterns through an interactive web interface, Nampyo News aims to support both academic research on media framing and public understanding of how news narratives differ across ideological lines.

## 2. 실험 개요

### 2.1 분석 대상

* **이슈**: 노란봉투법 관련 보도
* **기간**: 2025년 7월 1일 ~ 10월 28일 (총 119일)
* **언론사 (4개)**

  * 진보 성향: 경향신문, 한겨레
  * 보수 성향: 조선일보, 동아일보
* **기사 수**: 총 744건

### 2.2 분석 방법

1. **데이터 수집**

   * BIGKINDS에서 노란봉투법 관련 기사 및 메타데이터 수집
   * 제목, 본문, 언론사, 날짜, 키워드(TMS) 등 정보 확보

2. **진영 분류**

   * 경향신문·한겨레 → **blue(진보)**
   * 조선일보·동아일보 → **red(보수)**

3. **키워드 추출·전처리**

   * BIGKINDS가 제공하는 **키워드(명사)** 목록을 기사 단위로 추출
   * 의미 중복·불용 키워드 등을 전처리 후 집계

4. **빈도 분석**

   * 진영별로 키워드 출현 횟수를 합산
   * 전체 키워드 대비 비율(%)을 계산해 **상위 10개 키워드** 선정
   * 결과를 웹 UI에서 **막대 그래프/워드맵 등 시각화**로 표현

## 3. 주요 실험 결과

### 3.1 진보 언론 키워드 패턴

* **상위 10개 키워드 (일부)**

  * `봉투법(1.30%)`, `대통령(0.89%)`, `국민(0.80%)`, `정부(0.64%)`, `기업(0.55%)`,
    **`원청(0.53%)`, `노동자(0.46%)`, `교섭(0.44%)`, `노조(0.45%)`** 등

* **해석**

  * 보수 언론과 중복되지 않는 **‘노동자’, ‘원청’, ‘교섭’** 이 상위권에 위치
  * 가설 **H1-1**

    > “진보 언론은 노동 주체의 권리와 집단적 가치를 강조하는 키워드를 더 많이 사용할 것이다.”
    > 를 지지하는 결과
  * 노란봉투법을 **노동권 보호·집단 교섭·원청 책임**의 문제로 프레이밍하는 경향이 뚜렷함

### 3.2 보수 언론 키워드 패턴

* **상위 10개 키워드 (일부)**

  * `봉투법(1.46%)`, `대통령(1.28%)`, `기업(0.97%)`, `국민(0.76%)`, `정부(0.72%)`,
    **`민주당(0.69%)`, `통과(0.48%)`, `대표(0.46%)`, `노조(0.45%)`, `한국(0.39%)`** 등

* **해석**

  * 보수 진영 고유 키워드로 **‘민주당’, ‘대표’, ‘한국’** 이 상위권에 위치
  * **‘기업’** 비율은 0.97%로, 진보 언론(0.55%) 대비 약 **1.76배** 높게 나타남
  * 가설 **H1-2**

    > “보수 언론은 경제 주체의 부담과 시장 효율성을 강조하는 키워드를 더 많이 사용할 것이다.”
    > 를 부분적으로 지지
  * 기사 제목·리드에서 **헌법소원, 절차적 정당성, 청구 자격, 기업 부담** 등을 강조하는 프레임이 두드러짐

### 3.3 프레임 차이 요약

* **진보 언론**

  * “노동자–원청–교섭–노동권 보호”라는 **노동 중심 프레임**
* **보수 언론**

  * “민주당–대표–기업–헌법소원–부담”이라는 **정당·기업·절차 중심 프레임**

남표뉴스는 이 차이를 **인터랙티브 웹 UI**에서
검색어·기간만 바꾸어도 즉시 비교할 수 있도록 만든 도구입니다.

## 6. Roadmap (추후 개발 계획)

### 6.1 BIGKINDS API → 엑셀 + Naver API 기반으로 전환

BIGKINDS API 사용이 어려워진 환경을 고려해,
남표뉴스는 다음과 같이 **동일한 기능을 다른 데이터 소스로 유지**하는 방향으로 개발 중입니다.

* BIGKINDS에서 제공하는 **뉴스 엑셀 데이터**를 주기적으로 내려받아 저장
* 백엔드에서 엑셀을 읽어:

  * 기사 목록·메타데이터 로딩
  * 키워드(TMS) 컬럼으로 **진영별 키워드 빈도** 계산
* 프론트엔드는 기존과 동일한 API 응답 구조를 사용
  → 사용자 입장에서는 **기능·UI는 그대로**,
  내부적으로만 **“BIGKINDS API → BIGKINDS 엑셀 데이터”** 로 교체

### 6.2 Naver 실시간 뉴스 기능 유지·확장

* 실시간 뉴스 흐름은 계속 **Naver 뉴스 API + SSE**로 제공
* 추후 계획

  * 실시간 기사와 과거 프레이밍 통계를 연결해
    “방금 나온 기사 vs 누적 프레임 히스토리”를 함께 보여주는 기능 검토

### 6.3 분석 이슈 및 시각화 확장

* 노란봉투법 외에

  * 노동, 부동산, 환경, 젠더, 외교 등 이슈로 확장 예정
* 시각화 고도화

  * 시간에 따른 키워드 변화, 언론사별 비교 차트, 네트워크형 키워드 맵 등 추가 고려
